## Development

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [pnpm](https://pnpm.io/)

### Setup

```sh
pnpm install
```

### Start the development server

```sh
pnpm dev
```

### Build all packages

```sh
pnpm build
```

### Lint & format

```sh
pnpm lint
pnpm format
```

### Start Storybook

```sh
pnpm storybook
```

### Run tests

```sh
pnpm test
```
